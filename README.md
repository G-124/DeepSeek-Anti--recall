# DeepSeek-Anti--recall

## 简介
这是一个用于增强DeepSeek前端功能的油猴脚本
DeepSeek 防撤回脚本 防止DeepSeek撤回消息，被撤回的消息将保存在本地
添加到油猴脚本使用

## 安装

### 方法一：通过脚本管理器安装（推荐）
1. 确保已安装 Tampermonkey 或 Violentmonkey。
2. 点击以下链接即可安装：
   [点击安装](https://github.com/G-124/DeepSeek-Anti--recall/blob/main/DeepSeek-Anti--recall.js)

### 方法二：手动复制代码
1. 打开脚本文件：`dshelper.js`
2. 复制全部代码
3. 在脚本管理器中新建脚本，粘贴代码并保存

## 使用说明
安装后，访问 `https://chat.deepseek.com/` 页面，脚本会自动运行。
